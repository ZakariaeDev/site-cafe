☕ Café Website – Front-End Project

Projet Front-End consistant à concevoir un site web moderne et responsive pour un café.
L’objectif est de proposer une interface intuitive permettant de présenter le café, son menu, sa galerie et ses informations de contact.

🎯 Objectifs

Créer une interface utilisateur moderne et attrayante

Assurer une expérience responsive sur tous les écrans

Structurer le code de manière claire et maintenable

🛠️ Technologies utilisées

HTML5 – structure des pages

CSS3 – mise en forme et design responsive

JavaScript – interactions utilisateur

📄 Pages du site

Accueil : bannière, slogan, horaires, appels à l’action

À propos : présentation, histoire et valeurs du café

Menu : boissons, plats, desserts avec prix (cartes)

Galerie : photos du café, ambiance et produits

Contact : formulaire, adresse, téléphone, Google Maps et réseaux sociaux

📁 Structure du projet

Projet organisé avec une structure claire incluant :

pages HTML

fichiers CSS et JavaScript

dossier images et assets

📦 Livrables

Code Front-End structuré

Fichiers HTML, CSS et JavaScript

Ressources visuelles (images, icônes)
